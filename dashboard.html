⚙ Como usar

1
Instale as dependências: npm install
2
Edite bot.js: preencha MEU_NUMERO e GRUPOS_ALVO[]. Para descobrir os IDs dos grupos, inicie o bot e envie !grupos para ele.
3
Inicie o bot: node bot.js. Escaneie o QR Code com o WhatsApp do robô.
4
Antes do 09:05, envie as 10 mensagens do seu número pessoal para o número do bot, uma por uma. Cada mensagem será associada a um horário na ordem.
Comandos disponíveis (envie para o bot):
!status !grupos !limpar
